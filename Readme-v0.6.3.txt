CyAICodex 0.6.3 — English by default

New libraries now start in English, including the interface, tray menu,
assistant language and bundled example method. French remains available
from FR / EN or Settings > App language. Saved language choices are preserved.
Existing methods and images are not translated or replaced.

Run CyAICodex-Setup-0.6.3.exe to install or update.
Keep _internal next to CyAICodex.exe. Components are installed once.
Library data remains in %LOCALAPPDATA%\CyAICodex\data.
