Skill de référence

Votre conversation, le skill sélectionné et l’image choisie avec ses consignes sont envoyées au fournisseur. Le modèle doit accepter les images. Cet assistant analyse et rédige ; il ne génère pas encore d’images.

Connecter une IA en un clic

Choisissez l’accès, puis cliquez sur votre client. Sa configuration est sauvegardée avant modification ; ses autres serveurs sont conservés.

Le test ouvre une vraie session MCP avec la configuration enregistrée. Il ne peut pas garantir qu’une conversation déjà ouverte a rechargé ses outils : redémarrez le client ou reconnectez son serveur MCP après configuration.

Informations à transmettre à une autre IA

Lancez CyAICodex, puis configurez son serveur Streamable HTTP. Commencez par get_context, search_methods et get_method. Pour les images : search_images, view_image, puis import_image pour en ajouter.

Disponibilité du serveur

Démarrer avec Windows

Vérification…

À l’ouverture de votre session Windows, CyAICodex démarre discrètement dans la zone de notification. Le serveur reste actif lorsque vous fermez l’onglet. Il est indisponible lorsque le PC est éteint ou en veille.

VOTRE FONCTIONNEMENT

Paramètres

Langue de l’application

La langue est mémorisée sur ce PC. Les fiches et les images ne sont pas traduites.

Autorisations MCP

Tout client local pourra accéder au contexte ci-dessous. L’interface d’administration reste protégée. Les confirmations d’outils affichées par Codex ou Claude se règlent dans ces applications.

Les droits des connexions existantes se modifient dans Connexions. Le contexte reste toujours respecté.

Clients locaux de l’assistant

Détection automatique, y compris au démarrage de Windows. Un chemin personnalisé est facultatif.

Vérifier et connecter

Claude Desktop : créez une connexion dans Connexions puis choisissez « Claude Desktop · application ». Ajoutez le bloc généré à sa configuration MCP et redémarrez Claude. Cela donne à l’application Claude accès à votre bibliothèque. Pour discuter depuis CyAICodex, choisissez Claude Code et connectez votre compte Claude.

Ollama : choisissez un modèle installé. Si la liste est vide, installez-en un dans Ollama puis cliquez sur Vérifier. Les images nécessitent un modèle acceptant la vision.

Connecteurs supplémentaires

Enregistrez les réglages, vérifiez le client, puis testez une réponse. Le test envoie seulement un court message de contrôle au fournisseur choisi et peut consommer son quota.

Mises à jour

CyAICodex

Les mises à jour proviennent des releases GitHub de MrMybal/CyAICodex. L’installation conserve votre bibliothèque et vos réglages.

Accès au dépôt privé GitHub

Un dépôt public ne nécessite aucune connexion. Pour le dépôt privé, utilisez votre connexion Git locale ou un jeton GitHub limité à ce dépôt avec le droit Contents en lecture.

Le jeton est chiffré avec votre compte Windows. Il n’est jamais inclus dans l’application publiée.
