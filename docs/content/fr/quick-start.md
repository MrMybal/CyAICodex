## Premiers pas {#content}


1. Lancez l’installateur et conservez _internal à côté de CyAICodex.exe. Python n’est pas nécessaire pour la version installée.
2. Ouvrez CyAICodex depuis Démarrer, le raccourci ou l’icône verte CY avec un livre dans la zone de notification.
3. Dans Bibliothèque, ouvrez une checklist GitHub fournie ou cliquez sur Nouveau skill. Renseignez titre, résumé et consignes ; choisissez la portée puis Publié lorsque la fiche est prête.
4. Dans Connexions > Configurer et tester, choisissez client et droits, puis configurez et testez. Reconnectez le serveur MCP dans le client ou redémarrez ce client.
5. Demandez à l’IA d’appeler get_context, search_skills et get_skill. Un résultat publié dans la bonne portée confirme la lecture de la bibliothèque.
