## About, license and manual {#content}


Maintained by Cyberalien. CyAICodex uses GNU Affero General Public License version 3 only (AGPL-3.0-only). The installed LICENSE contains the complete terms. Third-party components retain their licenses.

The manual version is shown above. Screenshots contain sample data; small label or color differences may occur across releases. No account credentials or personal libraries are used as examples.

Open Documentation or press F1 in the app, use the Windows tray menu, or run CyAICodex.exe --open-help. CyDoc opens the bundled help/index.html through file://. Once open, reading, search, diagrams and images work without the application server or Internet. Existing /help links remain launchers while the app is running.

For support, describe the version, client and failed step with a redacted error. Repository and releases are on GitHub and require Internet access.
