CyAICodex — VERSION WINDOWS 0.2.0

Lancez CyAICodex.exe ou le raccourci du Bureau.
CyAICodex-MCP.exe est le relais pour Claude Desktop ; ne pas le lancer seul.
Les données et les connexions existantes sont conservées dans data.

Nouveautés : import_image par MCP, détection Codex sans dépendance au PATH,
clients Claude Code et OpenCode, Ollama local, onglet Paramètres.
Reconnectez vos clients MCP pour qu’ils découvrent le nouvel outil import_image.

Paramètres > Autorisations MCP : accès local sans jeton facultatif, contexte
et droit d’écriture séparés. Les confirmations des clients IA restent leurs réglages.
Connexions : les droits d’écriture existants se modifient directement.

Claude Code : cliquer Se connecter et terminer la connexion dans son terminal.
Claude Desktop : créer une connexion, choisir Claude Desktop dans les formats,
ajouter la configuration MCP à Claude et redémarrer cette application.
Ollama : Vérifier, choisir qwen3:0.6b, puis Utiliser ce modèle dans l’assistant.
Ce petit modèle est prévu pour le texte, pas pour les images.
OpenCode : se connecter à un fournisseur, ou utiliser ollama/qwen3:0.6b.

Fermer l’onglet ne coupe pas le serveur. Quitter depuis l’icône Windows pour l’arrêter.
Pour sauvegarder, quitter puis copier data. Journal : data/methodes.log.
