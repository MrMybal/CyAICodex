CyAICodex 0.6.1 — Exemple de méthode GitHub
Maintenance : Cyberalien

Une méthode d’exemple est ajoutée à la bibliothèque :
« Exemple — Confidentialité avant publication GitHub ».
Elle couvre les sources, l’historique Git, les données personnelles, les secrets,
les tests et le contenu des exécutables ou installateurs avant publication.

L’exemple est global et publié, donc consultable par MCP si la connexion inclut
les méthodes globales. Vous pouvez le modifier ou l’archiver. Une mise à jour
ne remplace pas vos adaptations et ne crée pas de doublon.
La version anglaise est utilisée si la bibliothèque est en anglais lors de l’ajout.

Installation : lancer CyAICodex-Setup-0.6.1.exe, ou utiliser Paramètres > Mises à jour.
CyAICodex.exe contient l’application et son transport MCP intégré.
Les données sont conservées dans %LOCALAPPDATA%\CyAICodex\data pour la version
installée et dans data à côté de l’exécutable pour la version portable.
