CyAICodex 0.5 — Connecteurs supplémentaires
Maintenance : Cyberalien

Démarrer : CyAICodex.exe. Gardez CyAICodex-MCP.exe à côté pour Claude Desktop.
La bibliothèque et les réglages sont conservés dans data.

Paramètres > Connecteurs supplémentaires :
- Antigravity (CLI agy)
- Command Code (CLI cmdc / command-code)
- CodeBuddy (CLI codebuddy / cbc)
- OpenRouter (clé API)
- LM Studio (serveur local)

Enregistrez les réglages avant de tester. Vérifier détecte le client ou le serveur.
Tester une réponse envoie un court message au fournisseur et peut consommer son quota.
Charger les modèles propose le catalogue réellement retourné lorsqu’il est disponible.
Utiliser dans l’assistant sélectionne le connecteur et le modèle choisis.

Les clients Codex, Claude Code, OpenCode, Ollama et les API existantes restent disponibles.
La connexion MCP de la bibliothèque se configure toujours dans Connexions.

Les nouveaux CLI acceptent le texte. Antigravity et Command Code utilisent leur mode
plan natif ; CodeBuddy démarre sans outils. Les droits natifs restent gérés par le client.
Les comptes des applications graphiques et des CLI peuvent être distincts.
Cette version affiche la réponse finale et renvoie l’historique de l’onglet à chaque
demande ; elle ne reprend pas de session native pour les nouveaux connecteurs.

Interface française et anglaise : sélecteur FR / EN ou Paramètres > Langue.
Pour sauvegarder : quitter depuis la zone de notification, puis copier le dossier data.
