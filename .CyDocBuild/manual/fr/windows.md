## Garder le serveur disponible {#content}


1. Dans Connexions > Disponibilité du serveur, activez Démarrer avec Windows, ou utilisez le même réglage dans le menu de l’icône.
2. À la prochaine connexion Windows, CyAICodex démarre discrètement sans ouvrir le navigateur. L’icône permet de le rouvrir.
3. Pour l’arrêter, choisissez Quitter et arrêter le serveur. Les clients perdent l’accès jusqu’au prochain lancement.

Le démarrage a lieu après la connexion utilisateur, pas avant. Le PC doit être éveillé. Fermer le navigateur n’arrête pas le serveur ; veille et arrêt du PC le rendent indisponible.

Si une adresse copiée demande de rouvrir depuis l’icône, utilisez l’icône ou le raccourci. Ce lancement établit la session d’administration protégée. Ne partagez pas le lien temporaire.
