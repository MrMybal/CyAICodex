La version du manuel est indiquée en haut. Les captures utilisent des données de démonstration ; certains libellés ou couleurs peuvent varier selon la version. Aucun identifiant ni bibliothèque personnelle ne sert d’exemple.

Ouvrez Documentation ou F1 dans l’application, utilisez le menu de l’icône Windows, ou lancez CyAICodex.exe --open-help. CyDoc ouvre Documentation/Documentation.html via file://. Une fois ouvert, lecture, recherche, schémas et images fonctionnent sans serveur applicatif ni Internet. Les anciens liens /help restent des lanceurs lorsque l’application tourne.

Pour le support, indiquez version, client et étape en échec avec l’erreur expurgée. Dépôt et releases GitHub nécessitent Internet.
