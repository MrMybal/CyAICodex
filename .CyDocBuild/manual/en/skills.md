## Write a Skill {#content}


1. Open Library > New skill, or click an existing card to edit it.
2. Use a specific title and summary explaining when the skill applies. Write prerequisites, ordered actions, expected result and checks in The skill.
3. Choose a category and comma-separated tags. Tags and summary help search; keep secrets and personal credentials out of reusable instructions.
4. Choose Global, Project type or Specific project, selecting the group where needed. Set Published, Draft or Archived, then save.

| Field | Purpose |
| --- | --- |
| Title / summary | What the skill does and when to consult it. |
| Content | Text with Markdown headings, steps and checklists. |
| Category / tags | Classification and search keywords. |
| Scope | Which project contexts may access the published skill. |
| Status | Published: visible through MCP. Draft / Archived: kept for you, excluded from MCP. |

To retire a skill, choose Archived and save. A draft can be refined before publishing. Changing interface language never translates or rewrites your content.

```callout
{"type": "tip", "title": "Remember", "body": "Library Skills are instruction records. They are not automatically created or installed as native SKILL.md packages in other software."}
```
