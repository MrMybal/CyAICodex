## Set up your library {#content}


1. Run the Windows installer and keep _internal and Documentation next to CyAICodex.exe. Python is not required for the installed version.
2. Open CyAICodex from Start, your shortcut or the green CY book icon in the Windows notification area.
3. In Library, open a bundled GitHub checklist or click New skill. Write a title, summary and instructions; choose a scope and Published when ready.
4. In Connections > Configure and test, choose your client and access settings, then configure and test. Reconnect the MCP server in the client or restart that client.
5. Ask the AI to call get_context, search_skills and get_skill. A published result in the intended scope confirms it can read the library.
